# Handover Skill

在长会话结束前，写一份交接文档到 `CONTINUE.md`，让新会话能无缝接手。

## 触发方式

在会话中输入：

```
请写一份交接文档存到 CONTINUE.md
```

## 交接文档模板

收到指令后，按以下结构写入项目根目录的 `CONTINUE.md`：

```markdown
# CONTINUE.md — 会话交接文档

> 最后更新：YYYY-MM-DD HH:MM

## 当前任务

一句话描述：我们在做什么、最终目标是什么。

## 已完成

- [x] 做完了什么
- [x] 做完了什么
- [ ] 这个只做了一半

## 当前状态

卡在哪里，遇到了什么问题，有什么还没解决。

## 下一步计划

1. 最优先做什么
2. 然后做什么
3. 最后做什么

## 踩坑记录

### 坑1：描述

- **现象**：报错 / 行为不符合预期
- **原因**：为什么会这样
- **解决 / 绕过**：怎么处理的（或者：还没解决）

### 坑2：描述

...

## 关键上下文

新会话需要知道的背景信息、文件路径、配置细节等。
```

## 执行要求

1. **从当前对话中提取信息**，不要编造
2. **踩坑记录要详细** — 包括具体报错、尝试过的方案、为什么不行
3. **下一步计划要具体** — 不要写"继续开发"，要写"先修 `src/api.ts` 里的鉴权逻辑，然后跑测试"
4. **只写到 `CONTINUE.md`**，不要改其他文件
5. 如果 `CONTINUE.md` 已存在，读取并更新，保留还有用的历史信息

## 新会话启动

下次开新会话时，第一句话：

```
先读 CONTINUE.md
```

AI 会读完交接文档，理解上下文后直接继续工作。
